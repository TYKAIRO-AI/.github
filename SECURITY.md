# TYKAIRO AI Security Policy

Security reports should be handled carefully and privately.

## Reporting

If you discover a security issue in a TYKAIRO AI public project:

- Do not publish secrets, credentials, personal data, or working exploit details in a public issue.
- Check the affected repository for a project-specific SECURITY.md and follow it first.
- Include the affected project/version, impact, reproduction details, and suggested mitigation when possible.

## Scope

Each repository defines its own supported versions and security boundaries. A public documentation repository may not contain the proprietary implementation of the corresponding product.

TYKAIRO AI does not claim that an automated security verdict is an absolute guarantee of safety.
