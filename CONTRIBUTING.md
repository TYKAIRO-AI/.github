# Contributing to TYKAIRO AI Projects

Thanks for your interest in TYKAIRO AI.

Public repositories may have different contribution and licensing rules. Always read the repository README and license before submitting work.

## Before contributing

1. Check existing issues and documentation.
2. Keep changes focused and explain the problem being solved.
3. Do not include credentials, private data, proprietary code, or third-party material you do not have permission to contribute.
4. Add or update tests when the repository contains an executable codebase.
5. Do not assume a public repository is open source; some TYKAIRO AI repositories are source-available or documentation-only.

## Security issues

Do not publish exploitable security details in a public issue. Follow the repository's SECURITY.md when available.

## Product ownership

TYKAIRO AI products are founded and developed under the direction of **Mahmoud Hisham**. Contributions do not transfer ownership of the underlying product, trademarks, or proprietary components unless explicitly agreed in writing.
