# TYKAIRO AI Support

For product questions, start with the README and documentation in the relevant repository.

When opening a public issue, include:

- product or repository name
- version or commit when relevant
- operating system/runtime when relevant
- expected behavior
- actual behavior
- minimal reproduction steps

Never include passwords, API keys, tokens, private customer data, or other secrets in an issue.

Commercial products and private editions may use separate support channels defined by their product listing or documentation.
